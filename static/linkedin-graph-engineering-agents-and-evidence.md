New article: Graph Engineering: Connecting Code, Agents, and Evidence Without Building a New Graph Database

Complex engineering systems rarely fail because information is missing. They fail because the important relationships are disconnected:

• code symbols from callers, tests, and deployments
• product contracts from browser, mobile, and security checks
• agent decisions from tool results and verification
• research links from experiments and consulting evidence

My approach is layered: Git-backed Markdown, durable memory, QMD, code intelligence, and live verification—each useful, but none automatically the source of truth.

The goal is an impact packet that answers what a shared-contract change affects and which checks are required. Start with one painful boundary, record the provenance of each relationship, and connect the graph to a deterministic verification step.

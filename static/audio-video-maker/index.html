Audio + image video maker

Turn a single image and an audio file into an MP4 locally in your browser. The output is encoded without real-time playback and is streamed to disk when your browser supports it.

JPEG, PNG, or WebP. The image is fitted inside the selected output size.

MP3, M4A/AAC, WAV, OGG/Opus, and some FLAC files are supported when your browser can decode them. Audio is re-encoded as AAC for MP4 compatibility.

1 fps is enough for a static image and keeps the file small.

Privacy and compatibility

Files stay on this device. Chrome or Edge on desktop is recommended because it supports WebCodecs and the File System Access API. Safari and Firefox may not support this tool yet. The fallback download keeps the encoded file in a Blob, so it is less suitable for very long recordings.

For a 2-hour source, browser audio decoding can still require substantial temporary memory. Close memory-heavy tabs first.

# Voice Summary Agent

Use the final article or an approved summary to create a concise spoken summary with the configured local Piper TTS voice. Save it under `assets/audio/`, verify format, size, and readability, and add an audio player reference only to the matching post. Do not upload or publish the audio externally without approval.

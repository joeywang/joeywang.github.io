# Publication Verifier

Proceed only with explicit Joey approval for publication. Move the approved draft to `_posts/`, preserve unrelated work, run front-matter, Jekyll build, link, and secret checks, and create a focused branch/PR following repository workflow. Verify the canonical URL only after deployment. Never merge, trigger sensitive deployment, or post to social channels without matching approval.

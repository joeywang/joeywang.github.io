3. execute through tools

## LinkedIn — cheaper, safer agents

A workflow that repeats should not stay as an expensive chat prompt forever.

Use:

- an LLM for judgment
- a workflow for repeatable decisions
- a script for deterministic work
- a command for a named capability
- cron or webhooks when timing should not depend on memory

That promotion makes agent systems cheaper, faster, and easier to verify.

https://joeywang.github.io/posts/golden-rules-for-cheaper-safer-llm-agents/
